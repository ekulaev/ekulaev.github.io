流畅地读谱

为数码钢琴设计的视奏练习器。用数据线连接平板、手机或电脑，就能开始弹。

打开练习器 免费。无需注册。

按乐句读谱，而不是一个音一个音地认

音列
从参考音找到第一个音，然后按音程往下弹。弹对了，提示就会逐步隐去。
轮廓
从任意琴键开始，弹出旋律的走向——上行、下行或同音。
节奏
在任意琴键上敲出节奏型。

难点会更常出现；每次练习结束，你都能看到哪里进步了。

字大清晰，按你的节奏来。

  • 大音符、高对比度，适合看小字吃力的人。
  • 没有倒计时，也没有“失败”：速度只在后台默默记录。
  • 手边没有钢琴？可以用屏幕键盘弹。

连上钢琴，开始弹奏

此浏览器无法连接钢琴。请在 Chrome 中打开本网站。

  1. 用 USB 数据线把钢琴连接到设备。
  2. 在 Chrome 中打开练习器。
  3. 允许访问钢琴。
  4. 点击“Start”。

你需要

一台带 USB 接口的数码钢琴；一台安卓平板或手机（接口不匹配时用 OTG 转接头），或一台装有 Windows、macOS 或 Linux 的电脑；Chrome 或 Edge 浏览器。

iPhone 和 iPad 无法使用：Safari 不能访问钢琴。屏幕键盘在任何设备上都能试用。

坦白说

  • 首次打开后，练习器无需联网即可使用。
  • 练习器不收集任何数据：练习进度只保存在你的设备上。
  • 本网站会统计访问量，详见“隐私”。
  • 练习器界面目前为英文。
